# MapleOCR Workflow

## Folder layout

```text
C:\MapleOCR
├─ screenshots\
│  └─ Equipped\
├─ Output\
├─ mapleexport.txt
├─ mapleupload.txt          generated by real run
├─ maplelocked.txt          generated by real run
└─ lock_status.txt          generated by real run
```

## Screenshot sources

```text
C:\MapleOCR\screenshots
```

Bag/current inventory screenshots.

```text
C:\MapleOCR\screenshots\Equipped
```

Currently worn equipment. These screenshots build Basic Preset.

## Safe run order

Always dry-run first:

```powershell
cd C:\MapleOCR
.\run_v180_full_inventory_dry_run.ps1
```

Check the output ZIP/report, then run real:

```powershell
cd C:\MapleOCR
.\run_v180_full_inventory.ps1
```

## Real output files

```text
C:\MapleOCR\mapleupload.txt
C:\MapleOCR\maplelocked.txt
C:\MapleOCR\lock_status.txt
```

## Current preset rules

Basic Preset is built from `screenshots\Equipped` and must also populate:

```text
equipmentPresets[0]
equippedItemsBySlot
equipmentBaseStats
```

Managed by OCR:

```text
Basic Preset
Arena
Colosseum
HP
MP
Chapter Boss
```

Left manual / optimiser-managed:

```text
Breakthrough
World Boss
Boss Raid HTE
Boss Raid ZAKVH
GD Weapon
GD Hero
GD Enhancement
GD Experience
GD Equipment
```

## Safety rules

- No stat scaling.
- Do not preserve stale optimiser inventory items.
- Fresh OCR screenshots are the source of truth for inventory.
- Dry-run must not overwrite real `mapleupload.txt`.
- Uncertain OCR goes to review, not into real output.
